# 14 - Future Features & Roadmap

## Product Enhancement Roadmap

### 1. Biometric & QR Code Gate Integration
- **Mobile QR Pass Generation**: Issue digital worker IDs with secure QR codes for site entry scanners.
- **Turnstile / Gate API**: Real-time HTTP webhook integration with physical site turnstiles to block entry if medical certificates or safety passes have expired.

### 2. Mobile App (iOS / Android)
- Native or Progressive Web App (PWA) for site supervisors to quickly scan worker badges and verify active compliance in offline mode.

### 3. Automated OCR Document Processing
- Automatic extraction of worker name, medical test date, and expiry dates from uploaded PDF/image medical certificates using Optical Character Recognition (OCR).

### 4. Advanced Contractor Evaluation Engine
- Multi-factor monthly vendor scoring based on document submission timeliness, safety incident history, and compliance pass rates.

### 5. Multi-Language Support (i18n)
- Support for regional languages (Hindi, Tamil, Kannada, Telugu, Bengali) in worker registration forms.
